@lesson Series и DataFrame
`Series` — одномерный столбец значений с индексом (подписями строк). `DataFrame` — таблица из нескольких Series с общим индексом: каждый столбец имеет свой тип.
Таблицу создают из словаря списков, читают из CSV через `pd.read_csv`, из Excel — `pd.read_excel`. Первые строки показывает `head()`, размер — `shape`, типы столбцов — `dtypes`, сводку по числовым столбцам — `describe()`.
Столбец берут как `df["price"]`, несколько — списком `df[["name", "price"]]`. Новый столбец создают присваиванием, и он вычисляется сразу для всех строк — векторизация, как в NumPy.
```code
import pandas as pd

df = pd.DataFrame({
    "name": ["Ада", "Алан", "Грейс", "Линус"],
    "city": ["Алматы", "Астана", "Алматы", "Шымкент"],
    "salary": [900, 1200, 1500, 700],
})
print(df.shape)                 # (4, 3)
print(df.head(2))
df["bonus"] = df["salary"] * 0.1
print(df["bonus"].tolist())     # [90.0, 120.0, 150.0, 70.0]
print(df["salary"].mean())      # 1075.0
print(df.describe().loc["max", "salary"])   # 1500.0
```
! Один столбец — `df["x"]` (Series), несколько — `df[["x", "y"]]` (DataFrame)
! Операции над столбцами векторизованы: никаких циклов по строкам
! `df.info()` показывает типы и число непустых значений в каждом столбце

@lesson Выбор строк: loc, iloc и фильтры
`loc` выбирает по меткам индекса и именам столбцов: `df.loc[3, "price"]`, `df.loc[df["age"] > 30, ["name"]]`. Срез в `loc` включает правую границу.
`iloc` выбирает по позициям, как в NumPy: `df.iloc[0]`, `df.iloc[:5, 1:3]`. Правая граница среза в `iloc` не включается.
Фильтр — это булева маска: `df[df["city"] == "Алматы"]`. Условия объединяют через `&` и `|` со скобками, для списка значений есть `isin`. Сортируют через `sort_values`, по убыванию — `ascending=False`.
```code
import pandas as pd

df = pd.DataFrame({
    "name": ["Ада", "Алан", "Грейс", "Линус", "Маргарет"],
    "age": [36, 41, 29, 33, 25],
    "lang": ["py", "java", "py", "c", "py"],
})
print(df.loc[1, "name"])                         # Алан
print(df.iloc[-1]["name"])                       # Маргарет
young_py = df[(df["age"] < 35) & (df["lang"] == "py")]
print(young_py["name"].tolist())                 # ['Грейс', 'Маргарет']
print(df[df["lang"].isin(["java", "c"])].shape)  # (2, 3)
print(df.sort_values("age", ascending=False)["name"].iloc[0])   # Алан
print(df.loc[0:2, "age"].tolist())               # [36, 41, 29] — граница включена
```
! В `loc` срез включает правую границу, в `iloc` — нет
! Изменяйте значения через `df.loc[mask, "col"] = value`, а не цепочкой `df[mask]["col"] = value`
! `isin` удобнее длинной цепочки условий через `|`
? out Что выведет код?

@lesson Очистка данных
Реальные данные грязные: пропуски, дубли, числа в виде строк, лишние пробелы. Пропуски находят через `isna().sum()`, удаляют — `dropna()`, заполняют — `fillna()`: медианой, средним или отдельным значением.
Дубли удаляет `drop_duplicates()`. Тип меняют через `astype`, а строки с мусором превращают в числа через `pd.to_numeric(..., errors="coerce")` — неподходящие значения станут NaN.
Текстовые столбцы чистят методами `.str`: `strip`, `lower`, `replace`, `contains`. Столбцы переименовывают через `rename(columns={...})`.
```code
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "city": [" Алматы", "алматы", "Астана", None, "Астана"],
    "price": ["100", "200", "abc", "150", "200"],
})
df["city"] = df["city"].str.strip().str.capitalize()
df["price"] = pd.to_numeric(df["price"], errors="coerce")
print(df["price"].isna().sum())               # 1 — "abc" стал NaN
df["price"] = df["price"].fillna(df["price"].median())
df = df.dropna(subset=["city"]).drop_duplicates()
print(df["city"].value_counts().to_dict())    # {'Алматы': 2, 'Астана': 2}
print(df["price"].tolist())                   # [100.0, 200.0, 175.0, 200.0]
```
! Сначала посчитайте пропуски `df.isna().sum()`, потом решайте, что с ними делать
! Медиана для заполнения устойчивее среднего к выбросам
! `errors="coerce"` превращает непарсящиеся значения в NaN, а не падает

@lesson Группировка и сводные таблицы
`groupby` разбивает таблицу на группы по значению столбца, применяет функцию к каждой и собирает результат: `df.groupby("city")["salary"].mean()`. Несколько функций сразу — через `agg`: `agg(["mean", "max"])` или именованно `agg(avg=("salary", "mean"))`.
`value_counts()` считает, сколько раз встречается каждое значение. `pivot_table` строит сводную таблицу: строки, столбцы, значения и функция агрегации — как в Excel.
`transform` возвращает результат той же длины, что и таблица: так добавляют, например, среднюю зарплату по городу в каждую строку.
```code
import pandas as pd

df = pd.DataFrame({
    "city": ["Алматы", "Астана", "Алматы", "Астана", "Алматы"],
    "level": ["junior", "junior", "senior", "senior", "junior"],
    "salary": [600, 650, 1800, 2000, 700],
})
print(df.groupby("city")["salary"].mean().to_dict())
# {'Алматы': 1033.3333333333333, 'Астана': 1325.0}

stats = df.groupby("level").agg(avg=("salary", "mean"), n=("salary", "size"))
print(stats.loc["junior", "n"], stats.loc["senior", "avg"])   # 3 1900.0

print(df["city"].value_counts().iloc[0])     # 3

pt = df.pivot_table(index="city", columns="level", values="salary", aggfunc="mean")
print(pt.loc["Астана", "senior"])            # 2000.0

df["city_avg"] = df.groupby("city")["salary"].transform("mean")
print(len(df["city_avg"]))                   # 5
```
! После `groupby` укажите столбец и функцию: `df.groupby("a")["b"].sum()`
! `size` считает строки в группе, `count` — непустые значения
! `transform` нужен, когда результат надо вернуть в исходную таблицу

@lesson Объединение таблиц
`pd.merge` соединяет таблицы по ключу, как JOIN в SQL. Параметр `how`: `inner` — только совпадающие ключи, `left` — все строки левой таблицы, `right`, `outer` — все строки обеих. Если ключи называются по-разному — `left_on` и `right_on`.
`pd.concat` склеивает таблицы одинаковой структуры друг под другом (`axis=0`) или рядом (`axis=1`). Для склейки по строкам часто нужен `ignore_index=True`.
После `left`-соединения строки без пары получают NaN — это удобный способ найти, например, клиентов без заказов.
```code
import pandas as pd

users = pd.DataFrame({"id": [1, 2, 3], "name": ["Ада", "Алан", "Грейс"]})
orders = pd.DataFrame({"user_id": [1, 1, 3], "total": [500, 300, 900]})

m = users.merge(orders, left_on="id", right_on="user_id", how="left")
print(len(m))                                   # 4
no_orders = m[m["total"].isna()]["name"].tolist()
print(no_orders)                                # ['Алан']

inner = users.merge(orders, left_on="id", right_on="user_id")
print(inner.groupby("name")["total"].sum().to_dict())   # {'Ада': 800, 'Грейс': 900}

jan = pd.DataFrame({"m": ["jan"], "sales": [10]})
feb = pd.DataFrame({"m": ["feb"], "sales": [12]})
print(pd.concat([jan, feb], ignore_index=True).shape)   # (2, 2)
```
! `how="inner"` по умолчанию: строки без пары исчезают
! После merge проверяйте число строк: дубли ключей размножают строки
! `concat` — склеить, `merge` — соединить по ключу

@lesson Даты, apply и подготовка признаков
Даты превращают из строк в тип datetime через `pd.to_datetime`, после чего доступны `.dt.year`, `.dt.month`, `.dt.dayofweek` и разница дат в днях. Таблицу с датами в индексе можно агрегировать по периодам через `resample("ME")` (по месяцам).
`apply` применяет функцию к каждому значению или строке, но это медленный цикл: если есть векторизованный способ (`np.where`, арифметика, методы `.str` и `.dt`), используйте его.
Категориальные признаки для моделей превращают в числа: `pd.get_dummies` создаёт по столбцу на каждое значение (one-hot). Это последний шаг перед передачей таблицы в scikit-learn.
```code
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "date": ["2026-01-15", "2026-01-20", "2026-02-03"],
    "amount": [120, 80, 200],
    "channel": ["web", "app", "web"],
})
df["date"] = pd.to_datetime(df["date"])
df["month"] = df["date"].dt.month
print(df["month"].tolist())                          # [1, 1, 2]
print((df["date"].max() - df["date"].min()).days)    # 19

df["big"] = np.where(df["amount"] >= 100, 1, 0)      # векторизованно вместо apply
print(df["big"].tolist())                            # [1, 0, 1]

monthly = df.set_index("date")["amount"].resample("ME").sum()
print(monthly.tolist())                              # [200, 200]

X = pd.get_dummies(df[["amount", "channel"]], columns=["channel"], dtype=int)
print(list(X.columns))       # ['amount', 'channel_app', 'channel_web']
```
! Даты сразу переводите в datetime — сравнение строк дат даёт ошибки
! `np.where(условие, a, b)` быстрее `apply` с if внутри
! `get_dummies` — быстрый one-hot; в проде лучше OneHotEncoder из scikit-learn
? out Что выведет код?
```code

```

= Между 1 и 11 марта 10 дней, оба в третьем месяце.

? mc Почему `apply` с обычной функцией стоит заменять векторизованными операциями?

- apply меняет порядок строк
- apply удаляет пропуски
