@lesson Figure, Axes и первый график
Matplotlib рисует на холсте `Figure`, внутри которого одна или несколько областей `Axes` — это и есть отдельные графики с осями. Современный способ — объектный: `fig, ax = plt.subplots()`, а потом методы `ax.plot`, `ax.set_title`, `ax.set_xlabel`.
`ax.plot(x, y)` рисует линию, параметры `label`, `color`, `linestyle`, `marker` задают оформление. Легенда появится после `ax.legend()`, сетка — после `ax.grid(True)`.
Готовый график сохраняют через `fig.savefig("plot.png", dpi=150)`, а показывают через `plt.show()`. В компиляторе AVALAND график появится прямо под выводом программы.
```code
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)
fig, ax = plt.subplots(figsize=(6, 3.5))
ax.plot(x, np.sin(x), label="sin(x)")
ax.plot(x, np.cos(x), label="cos(x)", linestyle="--")
ax.set_title("Синус и косинус")
ax.set_xlabel("x")
ax.set_ylabel("значение")
ax.legend()
ax.grid(True, alpha=0.3)
plt.show()
print(len(ax.lines))    # 2
```
! Пишите в объектном стиле `fig, ax = plt.subplots()` — так проще, когда графиков несколько
! Подписывайте оси и единицы измерения: график без подписей не читается
! `figsize` задаётся в дюймах: (ширина, высота)

@lesson Типы графиков: что когда рисовать
Тип графика выбирают по вопросу к данным. Линия `plot` — изменение во времени. Точки `scatter` — связь двух числовых признаков. Столбцы `bar` — сравнение категорий. Гистограмма `hist` — распределение одного признака. Ящик с усами `boxplot` — медиана, разброс и выбросы.
У гистограммы главный параметр — число корзин `bins`: слишком мало — не видно формы, слишком много — шум. `ax.hist` возвращает частоты, границы корзин и сами столбики.
У `scatter` размер и цвет точек могут показывать ещё два признака: `s=` и `c=` вместе с `cmap` и `colorbar`.
```code
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
area = rng.uniform(30, 120, 80)
price = area * 450 + rng.normal(0, 6000, 80)

fig, axs = plt.subplots(1, 3, figsize=(11, 3.2))
axs[0].scatter(area, price, s=12, alpha=0.7)
axs[0].set_title("Цена от площади")
counts, edges, _ = axs[1].hist(price, bins=10)
axs[1].set_title("Распределение цен")
axs[2].bar(["Алматы", "Астана", "Шымкент"], [540, 510, 330])
axs[2].set_title("Средняя цена, тыс.")
fig.tight_layout()
plt.show()
print(int(counts.sum()), len(edges))    # 80 11
```
! Распределение — `hist`, связь двух чисел — `scatter`, категории — `bar`
! У `hist` число границ на одну больше числа корзин
! `alpha` делает точки прозрачными, когда их много и они перекрываются

@lesson Несколько графиков и оформление
`plt.subplots(nrows, ncols)` создаёт сетку графиков; `axs` — массив Axes, к ним обращаются как `axs[0, 1]`. Параметры `sharex=True` и `sharey=True` выравнивают шкалы — так графики честно сравнивать.
`fig.tight_layout()` или `layout="constrained"` убирают наложение подписей. Пределы осей задают через `set_xlim`/`set_ylim`, логарифмическую шкалу — через `set_yscale("log")`.
Подписи прямо на графике делает `ax.annotate` или `ax.text`, горизонтальную линию-ориентир — `ax.axhline`. Общий заголовок для всей фигуры — `fig.suptitle`.
```code
import numpy as np
import matplotlib.pyplot as plt

epochs = np.arange(1, 21)
train_loss = 1.5 * np.exp(-epochs / 5) + 0.05
val_loss = 1.5 * np.exp(-epochs / 6) + 0.12 + 0.004 * epochs ** 1.5

fig, axs = plt.subplots(1, 2, figsize=(9, 3.2), sharey=True, layout="constrained")
axs[0].plot(epochs, train_loss, label="train")
axs[0].plot(epochs, val_loss, label="validation")
best = int(np.argmin(val_loss)) + 1
axs[0].axvline(best, color="gray", linestyle=":")
axs[0].annotate(f"лучшая эпоха {best}", (best, val_loss[best - 1]), xytext=(best + 2, 0.9))
axs[0].legend()
axs[1].plot(epochs, val_loss - train_loss, color="crimson")
axs[1].set_title("Разрыв = переобучение")
fig.suptitle("Кривые обучения")
plt.show()
print(axs.shape)        # (2,)
```
! `sharey=True`, когда графики нужно сравнивать по одной шкале
! Кривые обучения train и validation — главный график ML-инженера: расходятся — модель переобучается
! При nrows и ncols больше 1 `axs` — двумерный массив

@lesson Графики из pandas и разведочный анализ
У таблиц pandas есть метод `plot`, который вызывает Matplotlib: `df.plot(x="date", y="sales")`, `df["price"].plot(kind="hist")`, `df.groupby("city")["price"].mean().plot(kind="bar")`. Он возвращает Axes, так что дальше работают обычные методы.
Разведочный анализ (EDA) идёт по шагам: размер и типы, пропуски, распределение каждого признака, выбросы, связь признаков с целевой переменной и друг с другом.
Корреляционную матрицу `df.corr()` удобно показать как тепловую карту через `ax.imshow` и `fig.colorbar`. Сильная корреляция двух признаков между собой — повод убрать один из них.
```code
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
n = 200
df = pd.DataFrame({"area": rng.uniform(30, 120, n), "rooms": rng.integers(1, 5, n)})
df["price"] = df["area"] * 400 + df["rooms"] * 5000 + rng.normal(0, 5000, n)

corr = df.corr()
fig, axs = plt.subplots(1, 2, figsize=(10, 3.6))
df["price"].plot(kind="hist", bins=20, ax=axs[0], title="Цена")
im = axs[1].imshow(corr, cmap="coolwarm", vmin=-1, vmax=1)
axs[1].set_xticks(range(3), corr.columns)
axs[1].set_yticks(range(3), corr.columns)
fig.colorbar(im, ax=axs[1])
fig.tight_layout()
plt.show()
print(corr.loc["area", "price"] > 0.8)    # True
```
! `df.plot(..., ax=ax)` рисует в нужную область сетки
! Корреляция показывает только линейную связь и не доказывает причину
! EDA до обучения экономит часы: выбросы и утечки видно на графиках
? mc С чего начинается разведочный анализ данных?
+ С размера, типов столбцов и пропусков, потом распределения признаков
- С обучения сложной модели
- С подбора гиперпараметров
- С удаления всех выбросов
= Сначала понимают, что за данные и насколько они чистые.
? out Что выведет код?

@lesson Графики качества модели
После обучения модель тоже проверяют графиками. Для регрессии — предсказание против факта: точки должны лежать около диагонали `y = x`. Для классификации — матрица ошибок `confusion_matrix` в виде тепловой карты и ROC-кривая.
Остатки (факт минус предсказание) не должны иметь закономерности: если в них виден наклон или дуга, модель упускает зависимость.
Важность признаков из модели (`feature_importances_` у деревьев) рисуют горизонтальными столбцами `barh`, отсортированными по убыванию.
```code
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(3)
y_true = rng.uniform(10, 100, 60)
y_pred = y_true + rng.normal(0, 6, 60)

fig, axs = plt.subplots(1, 2, figsize=(9, 3.6))
axs[0].scatter(y_true, y_pred, s=14)
lims = [0, 110]
axs[0].plot(lims, lims, color="gray", linestyle="--")
axs[0].set_xlabel("факт"); axs[0].set_ylabel("прогноз")

names = np.array(["площадь", "комнаты", "этаж", "год"])
imp = np.array([0.55, 0.25, 0.05, 0.15])
order = np.argsort(imp)
axs[1].barh(names[order], imp[order])
axs[1].set_title("Важность признаков")
fig.tight_layout()
plt.show()
print(names[order][-1])     # площадь
```
! Предсказание против факта: чем ближе к диагонали, тем лучше
! Закономерность в остатках — модель недоучила зависимость
! Сортируйте столбцы важности, иначе график трудно читать
? mc Точки «прогноз против факта» лежат выше диагонали при больших значениях. Что это значит?
+ Модель систематически завышает прогноз для больших значений
- Модель идеальна
- Данных слишком мало
- Нужно сменить цвет точек
= Систематическое отклонение от диагонали — смещение модели в этой области.
? out Что выведет код?

> [0 2 1]
= argsort возвращает индексы по возрастанию значений: 0.1, 0.3, 0.6.

- Чёткий наклон вверх
- Дуга
+ Случайное облако вокруг нуля без закономерностей
- Все точки на одной прямой выше нуля
