@lesson Маршруты и контроллеры
Новый проект: `composer create-project laravel/laravel shop`, запуск — `php artisan serve`. Маршруты описывают в `routes/web.php` (страницы) и `routes/api.php` (API).
`Route::get('/courses/{id}', [CourseController::class, 'show'])` связывает адрес с методом контроллера. Параметры пути попадают в аргументы метода. Имя маршрута `->name('courses.show')` позволяет строить ссылки `route('courses.show', 7)`.
Контроллер создаёт Artisan: `php artisan make:controller CourseController --resource` — сразу с методами index, create, store, show, edit, update, destroy.
```code
<?php
// routes/web.php
use App\Http\Controllers\CourseController;
use Illuminate\Support\Facades\Route;

Route::get('/', fn () => view('welcome'));
Route::get('/courses', [CourseController::class, 'index'])->name('courses.index');
Route::get('/courses/{id}', [CourseController::class, 'show'])->whereNumber('id')->name('courses.show');
Route::resource('lessons', LessonController::class)->only(['index', 'show']);

// app/Http/Controllers/CourseController.php
namespace App\Http\Controllers;

class CourseController extends Controller
{
    private array $courses = [1 => 'PHP', 2 => 'Laravel'];

    public function index()
    {
        return view('courses.index', ['courses' => $this->courses]);
    }

    public function show(int $id)
    {
        abort_unless(isset($this->courses[$id]), 404);
        return view('courses.show', ['title' => $this->courses[$id]]);
    }
}
```
! `php artisan route:list` показывает все маршруты
! Ссылки стройте через `route('имя')`, а не вручную
! `abort(404)` — правильный ответ на несуществующий объект

@lesson Шаблоны Blade
Blade — шаблонизатор Laravel. Файлы `resources/views/*.blade.php`, вызов — `view('courses.show', [...])`. Вывод `{{ $title }}` автоматически экранирует HTML и защищает от XSS; `{!! $html !!}` — без экранирования, только для доверенного содержимого.
Директивы: `@if`, `@foreach`, `@forelse ... @empty`, `@auth`, `@csrf`. Общий каркас страницы — макет: `@extends('layouts.app')` и `@section('content')`, или компоненты `<x-card>`.
Каждая форма с POST должна содержать `@csrf` — токен защиты от подделки запросов.
```code
{{-- resources/views/layouts/app.blade.php --}}
<html>
<body>
  <nav>@auth Привет, {{ auth()->user()->name }} @else <a href="{{ route('login') }}">Войти</a> @endauth</nav>
  <main>@yield('content')</main>
</body>
</html>

{{-- resources/views/courses/index.blade.php --}}
@extends('layouts.app')

@section('content')
  <h1>Курсы ({{ count($courses) }})</h1>
  @forelse ($courses as $id => $title)
    <a href="{{ route('courses.show', $id) }}">{{ $title }}</a>
  @empty
    <p>Курсов пока нет</p>
  @endforelse

  <form method="POST" action="{{ route('courses.store') }}">
    @csrf
    <input name="title" value="{{ old('title') }}">
    @error('title') <small>{{ $message }}</small> @enderror
    <button>Создать</button>
  </form>
@endsection
```
! `{{ }}` экранирует HTML — используйте его по умолчанию
! `@csrf` обязателен в каждой POST-форме
! `old('поле')` возвращает введённое значение после ошибки валидации

@lesson Валидация и запросы
Данные формы приходят в объекте `Request`. Метод `$request->validate([...])` проверяет поля по правилам: `required`, `string`, `max:255`, `email`, `unique:users,email`, `integer`, `min:1`. При ошибке Laravel сам вернёт пользователя на форму с сообщениями.
Для сложных правил создают Form Request: `php artisan make:request StoreCourseRequest` — правила и авторизация в отдельном классе, контроллер остаётся коротким.
После успешного сохранения делают редирект с сообщением: `return redirect()->route('courses.index')->with('status', 'Курс создан')`.
```code
<?php
namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class StoreCourseRequest extends FormRequest
{
    public function authorize(): bool
    {
        return $this->user()?->is_admin ?? false;
    }

    public function rules(): array
    {
        return [
            'title' => ['required', 'string', 'max:120', 'unique:courses,title'],
            'price' => ['required', 'integer', 'min:0'],
            'level' => ['required', 'in:beginner,middle,advanced'],
        ];
    }
}

```

! `$request->validated()` — только проверенные поля

@lesson Artisan, конфиг и middleware
Artisan — консоль Laravel: `make:model`, `make:migration`, `migrate`, `tinker` (интерактивная консоль с доступом к приложению), `queue:work`, `schedule:run`. Свои команды — `php artisan make:command`.
Настройки берут из `.env` (пароли, ключи, адрес базы) через `config/*.php`: в коде пишут `config('app.name')`, а не `env()` напрямую. `.env` не коммитят в Git.
Middleware — слои вокруг запроса: `auth` пускает только вошедших, `throttle:60,1` ограничивает частоту, свои — `php artisan make:middleware`. Подключают к маршрутам: `Route::middleware('auth')->group(...)`.
```code
<?php
// app/Http/Middleware/EnsureUserIsAdmin.php
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;

class EnsureUserIsAdmin
{
    public function handle(Request $request, Closure $next)
    {
        if (! $request->user()?->is_admin) {
            abort(403, 'Только для администраторов');
        }
        return $next($request);
    }
}

// routes/web.php
// Route::middleware(['auth', EnsureUserIsAdmin::class])->prefix('admin')->group(function () {
//     Route::resource('courses', Admin\CourseController::class);
// });

// .env:  APP_ENV=production  DB_PASSWORD=секрет
// config/services.php: 'stripe' => ['key' => env('STRIPE_KEY')]
// в коде: config('services.stripe.key')
```
! `.env` — в `.gitignore`, в репозитории только `.env.example`
! В коде читайте `config()`, а `env()` — только в файлах config
! Группы маршрутов с middleware — вместо проверок в каждом контроллере
