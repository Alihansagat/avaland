@lesson Переменные, типы и ввод-вывод
В Python тип не объявляют: переменная — это имя, которое ссылается на объект, а тип есть у объекта. Основные встроенные типы: `int`, `float`, `str`, `bool` и `None`.
`input()` всегда возвращает строку, поэтому число из ввода нужно явно привести через `int()` или `float()`. Узнать тип можно через `type()`, а проверить — через `isinstance()`.
Деление `/` всегда даёт float, `//` делит нацело с округлением вниз, `%` — остаток, `**` — степень.
```code
name = input("Имя: ")          # всегда str
age = int(input("Возраст: "))  # приводим к int
print(f"{name}, через год вам {age + 1}")
print(7 / 2, 7 // 2, 7 % 2, 2 ** 10)  # 3.5 3 1 1024
print(-7 // 2)                  # -4: округление вниз
print(isinstance(age, int))     # True
```
! `input()` возвращает строку: `"5" + 1` вызовет TypeError
! `//` округляет вниз, а не к нулю: `-7 // 2 == -4`
! f-строки — самый читаемый способ форматирования

@lesson Условия и циклы
Блоки в Python задаются отступами, а не скобками. Условия пишут через `if`, `elif`, `else`. Пустые коллекции, `0`, `""` и `None` считаются ложными.
`for` перебирает элементы любой коллекции. `range(start, stop, step)` генерирует числа без включения `stop`. `enumerate()` даёт индекс и значение сразу.
`while` повторяет, пока условие истинно. `break` выходит из цикла, `continue` переходит к следующей итерации. У циклов есть `else`: он выполняется, если цикл не был прерван через break.
```code
for i, ch in enumerate("abc"):
    print(i, ch)

n = 10
while n > 0:
    n -= 3
print(n)              # -2

for x in [3, 5, 7]:
    if x % 2 == 0:
        break
else:
    print("чётных нет")
```
! `range(5)` — это 0, 1, 2, 3, 4
! Пустой список в условии ложен: `if items:` проверяет непустоту
! Тернарный оператор: `a if условие else b`

@lesson Строки
Строки неизменяемы: методы вроде `upper()` или `replace()` возвращают новую строку. Срезы `s[start:stop:step]` работают как у списков, а `s[::-1]` разворачивает строку.
`split()` режет строку в список, `join()` склеивает список в строку. `strip()` убирает пробелы по краям. Проверка вхождения — оператор `in`.
Склеивание в цикле через `+=` медленно на больших объёмах: правильнее собрать части в список и вызвать `"".join(parts)`.
```code
s = "  Hello, World  "
t = s.strip().lower()           # "hello, world"
words = t.split(", ")           # ["hello", "world"]
print("-".join(words))          # hello-world
print(t[::-1])                  # dlrow ,olleh
print("wor" in t, t.count("o")) # True 2
print(f"{3.14159:.2f}")         # 3.14
```
! `s[0] = "X"` вызовет TypeError: строки не меняются
! `split()` без аргумента режет по любым пробелам и убирает пустые части
! Формат `{x:.2f}` оставляет два знака после точки

@lesson Коллекции: list, tuple, set, dict
`list` — изменяемый упорядоченный список. `tuple` — неизменяемый кортеж, его можно использовать как ключ словаря. `set` — множество уникальных значений с быстрой проверкой `in`. `dict` — словарь ключ–значение.
Присваивание не копирует: `b = a` создаёт второе имя для того же списка. Копию делают через `a.copy()` или `list(a)`, а для вложенных структур нужен `copy.deepcopy`.
Проверка `x in set` и `key in dict` в среднем занимает O(1), а `x in list` — O(n).
```code
nums = [3, 1, 2]
nums.sort()                  # меняет список на месте
point = (10, 20)
x, y = point                 # распаковка
seen = {1, 2, 2, 3}          # {1, 2, 3}
ages = {"Ада": 36}
ages["Алан"] = 41
print(ages.get("Боб", 0))    # 0
for name, age in ages.items():
    print(name, age)
```

@lesson Функции
Функцию объявляют через `def`. Аргументы можно передавать по позиции и по имени. `*args` собирает лишние позиционные аргументы в кортеж, `**kwargs` — именованные в словарь.
Значения по умолчанию вычисляются один раз при объявлении функции. Поэтому изменяемый объект по умолчанию (`[]`, `{}`) будет общим для всех вызовов. Используйте `None` и создавайте список внутри.
Переменная, которой присваивают значение внутри функции, локальна. Чтобы изменить глобальную, нужен `global`, но лучше возвращать значение.
```code
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

def stats(*nums, round_to=2):
    return round(sum(nums) / len(nums), round_to)

print(stats(1, 2, 4))          # 2.33
print(stats(1, 2, round_to=0)) # 2.0
```
! Никогда не пишите `def f(x=[])` — список станет общим
! Без return функция вернёт None
! Функции — объекты: их можно передавать в другие функции

@lesson Comprehensions, генераторы и lambda
List comprehension строит список в одну строку: `[выражение for x in коллекция if условие]`. Так же пишутся dict и set comprehension.
Генератор отдаёт значения по одному и не держит всё в памяти. Генераторное выражение пишут в круглых скобках, а функция-генератор использует `yield`. Генератор можно пройти только один раз.
`lambda` — короткая безымянная функция в одно выражение. Чаще всего её передают в `sorted(key=...)`, `max(key=...)`, `map` и `filter`.
```code
squares = [n * n for n in range(6) if n % 2 == 0]  # [0, 4, 16]
lengths = {w: len(w) for w in ["code", "map"]}     # {'code': 4, 'map': 3}
total = sum(n * n for n in range(1_000_000))       # без списка в памяти

def countdown(n):
    while n > 0:
        yield n
        n -= 1

print(list(countdown(3)))                          # [3, 2, 1]
users = [("Ада", 36), ("Алан", 41)]
print(max(users, key=lambda u: u[1]))              # ('Алан', 41)
```
! Генератор исчерпывается: второй проход вернёт пусто
! Сложную логику не пихайте в comprehension — пишите обычный цикл
! `key=` в sorted принимает функцию, а не результат её вызова

@lesson ООП: классы, наследование, dataclass
Класс объединяет данные и поведение. `__init__` заполняет новый объект, `self` — ссылка на него. Атрибуты класса общие для всех экземпляров, атрибуты через `self` — у каждого свои.
Наследование указывают в скобках: `class Admin(User)`. `super()` вызывает метод родителя. Магические методы вроде `__str__`, `__eq__`, `__len__` задают поведение встроенных операций.
`@property` превращает метод в атрибут только для чтения. `@dataclass` сам пишет `__init__`, `__repr__` и `__eq__` для классов-хранилищ данных.
```code
from dataclasses import dataclass

class User:
    def __init__(self, name):
        self.name = name
    def greet(self):
        return f"Привет, {self.name}"

class Admin(User):
    def greet(self):
        return super().greet() + " (админ)"

@dataclass
class Point:
    x: int
    y: int

print(Admin("Ада").greet())        # Привет, Ада (админ)
print(Point(1, 2) == Point(1, 2))  # True
```
! Без `__eq__` два одинаковых объекта не равны: сравниваются ссылки
! Изменяемый атрибут класса (список) станет общим для всех объектов
! Наследуйте, только если «является», иначе используйте композицию

@lesson Исключения, файлы и модули
Ошибки обрабатывают через `try` / `except`. Ловите конкретные исключения, а не все подряд. Блок `else` выполняется, если ошибки не было, `finally` — всегда. Свою ошибку выбрасывают через `raise`.
Файлы открывают через `with open(...)`: файл закроется сам, даже если внутри произошла ошибка. Указывайте `encoding="utf-8"`.
Любой .py файл — модуль. Код под `if __name__ == "__main__":` выполняется только при прямом запуске файла. Зависимости ставят через `pip` в виртуальное окружение: `python -m venv .venv`.
```code
import json

def load(path):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError as e:
        raise ValueError(f"Файл повреждён: {e}") from e

if __name__ == "__main__":
    print(load("data.json"))
```
! Голый `except:` ловит даже Ctrl+C — так делать нельзя
! `with` закрывает файл автоматически
! Для каждого проекта — своё виртуальное окружение и requirements.txt
