@lesson Переменные, типы и функции
Переменные по умолчанию неизменяемы: `let x = 5`. Чтобы менять, нужен `let mut`. Повторный `let` с тем же именем создаёт новую переменную (shadowing) — можно даже сменить тип.
Целые типы указывают размер: `i32`, `u64`, `usize` для индексов. В отладочной сборке переполнение вызывает панику. Строковые литералы имеют тип `&str`, а изменяемая строка — `String`.
Почти всё в Rust — выражения. Последнее выражение функции без точки с запятой — её результат. `if` тоже возвращает значение.
```rust
fn area(w: u32, h: u32) -> u32 {
    w * h                       // без ; — это возвращаемое значение
}

fn main() {
    let name = "Ада";
    let mut score = 10;
    score += 5;

    let input = "42";
    let input: i32 = input.parse().unwrap();   // shadowing со сменой типа

    let status = if score > 10 { "pro" } else { "new" };
    println!("{name}: {score}, {status}, {}", area(2, input as u32));
}
```

@lesson Управление потоком и match
`if` — выражение, условие должно быть типа bool (никакого приведения чисел). Циклы: `loop` (бесконечный, может вернуть значение через `break значение`), `while` и `for x in коллекция`.
Диапазоны: `0..5` без верхней границы, `0..=5` включительно. Метки `'outer:` позволяют выйти из вложенного цикла.
`match` сравнивает с образцами: значения, диапазоны, кортежи, с условиями-охранниками `if`. Он обязан покрыть все варианты. `if let` — короткая форма для одного образца.
```rust
fn classify(n: i32) -> &'static str {
    match n {
        i32::MIN..=-1 => "отрицательное",
        0 => "ноль",
        x if x % 2 == 0 => "чётное",
        _ => "нечётное",
    }
}

fn main() {
    let mut count = 0;
    let result = loop {
        count += 1;
        if count == 3 { break count * 10; }
    };
    for i in (1..=3).rev() { print!("{i} "); }     // 3 2 1
    println!("{result} {}", classify(7));          // 30 нечётное

    let point = (0, 5);
    match point {
        (0, y) => println!("на оси Y: {y}"),
        (x, 0) => println!("на оси X: {x}"),
        _ => println!("где-то ещё"),
    }
}
```

! loop может вернуть значение через break
! `_` в match ловит всё остальное

@lesson Владение и заимствование
Владение — главная идея Rust. У каждого значения один владелец. Когда владелец выходит из области видимости, значение уничтожается. Присваивание `String` другой переменной перемещает владение — старая переменная становится недоступной.
Чтобы использовать значение без передачи владения, его заимствуют по ссылке: `&T` — читать, `&mut T` — менять. Правило: либо сколько угодно `&T`, либо ровно одна `&mut T` одновременно.
Эти правила проверяет borrow checker при компиляции. Поэтому в Rust нет висячих указателей и гонок данных в безопасном коде.
```rust
fn len(s: &String) -> usize { s.len() }        // заимствование
fn shout(s: &mut String) { s.push('!'); }      // изменяемое заимствование

fn main() {
    let a = String::from("hi");
    let b = a;                 // владение перешло к b
    // println!("{a}");        // ошибка: a перемещена

    let mut c = b.clone();     // явная глубокая копия
    shout(&mut c);
    println!("{} {}", len(&b), c);   // 2 hi!

    let n = 5;
    let m = n;                 // i32 реализует Copy — n доступна
    println!("{n} {m}");
}
```
! Простые типы (числа, bool, char) копируются, String и Vec — перемещаются
! clone() делает дорогую копию — используйте осознанно
! Нельзя одновременно иметь &mut и & на одно значение

@lesson Структуры и перечисления
`struct` объединяет данные, методы пишут в блоке `impl`. `&self` — метод читает объект, `&mut self` — меняет, `self` — забирает владение. Функции без self (например `new`) вызывают через `::`.
`enum` в Rust — алгебраический тип: каждый вариант может хранить свои данные. `match` разбирает варианты и обязан покрыть все — компилятор проверит.
`Option<T>` заменяет null: `Some(value)` или `None`. Работать с отсутствующим значением без проверки невозможно.
```rust
struct Account { owner: String, balance: i64 }

impl Account {
    fn new(owner: &str) -> Self { Self { owner: owner.into(), balance: 0 } }
    fn deposit(&mut self, sum: i64) { self.balance += sum; }
}

enum Command {
    Quit,
    Move { x: i32, y: i32 },
    Say(String),
}

fn run(c: &Command) -> String {
    match c {
        Command::Quit => "выход".into(),
        Command::Move { x, y } => format!("в {x},{y}"),
        Command::Say(text) => text.clone(),
    }
```

@lesson Ошибки: Result и оператор ?
Восстановимые ошибки возвращают через `Result<T, E>`: `Ok(value)` или `Err(error)`. Исключений в Rust нет.
Оператор `?` разворачивает Ok или сразу возвращает Err из функции. Он делает обработку ошибок короткой и явной.
`unwrap()` и `expect()` паникуют при ошибке — допустимы в прототипах и тестах, но не в продакшене. В приложениях удобен крейт `anyhow`, в библиотеках — свои типы ошибок через `thiserror`.
```rust
use std::fs;
use std::num::ParseIntError;

fn parse_sum(a: &str, b: &str) -> Result<i32, ParseIntError> {
    let x: i32 = a.trim().parse()?;
    let y: i32 = b.trim().parse()?;
    Ok(x + y)
}

fn read_config(path: &str) -> anyhow::Result<String> {
    let text = fs::read_to_string(path)
        .map_err(|e| anyhow::anyhow!("не удалось прочитать {path}: {e}"))?;
    Ok(text)
}

match parse_sum("2", "x") {
    Ok(s) => println!("{s}"),
    Err(e) => eprintln!("ошибка: {e}"),
}
```
! `?` работает только в функциях, возвращающих Result или Option
! panic! — для багов, Result — для ожидаемых ошибок
! eprintln! пишет в поток ошибок

@lesson Коллекции и итераторы
`Vec<T>` — растущий массив, `HashMap<K, V>` — словарь, `HashSet<T>` — множество. Срез `&[T]` — заимствованный вид на часть массива или вектора.
Итераторы ленивые: `iter()` даёт ссылки, `into_iter()` забирает элементы, `iter_mut()` даёт изменяемые ссылки. Цепочки `map`, `filter`, `sum`, `collect` компилируются в такой же быстрый код, как ручной цикл.
`entry` API у HashMap удобно для подсчётов: `*map.entry(k).or_insert(0) += 1`.
```rust
use std::collections::HashMap;

let nums = vec![1, 2, 3, 4, 5];
let evens: Vec<i32> = nums.iter().filter(|&&n| n % 2 == 0).copied().collect();
let total: i32 = nums.iter().map(|n| n * n).sum();       // 55

let text = "a b a c a";
let mut counts: HashMap<&str, usize> = HashMap::new();
for w in text.split_whitespace() {
    *counts.entry(w).or_insert(0) += 1;
}
println!("{:?} {} {}", evens, total, counts["a"]);  // [2, 4] 55 3

let first_two = &nums[..2];                          // срез [1, 2]
```

! Индекс за пределами вектора — паника, get(i) вернёт Option

@lesson Трейты и generics
Трейт описывает поведение, как интерфейс: `trait Summary { fn summary(&self) -> String; }`. Тип реализует трейт через `impl Trait for Type`. Можно задать реализацию по умолчанию.
Generics с ограничениями трейтами: `fn print_all<T: Display>(items: &[T])`. Компилятор создаёт отдельную быструю версию для каждого типа (мономорфизация).
`dyn Trait` — динамическая диспетчеризация, когда нужен список объектов разных типов: `Vec<Box<dyn Shape>>`. Стандартные трейты: `Debug`, `Clone`, `PartialEq`, `Display`, `From`, `Iterator`.
```rust
use std::fmt;

trait Shape { fn area(&self) -> f64; }

struct Circle(f64);
struct Square(f64);

impl Shape for Circle { fn area(&self) -> f64 { 3.14 * self.0 * self.0 } }
impl Shape for Square { fn area(&self) -> f64 { self.0 * self.0 } }

impl fmt::Display for Square {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "Квадрат {}", self.0)
    }
}

fn largest<T: PartialOrd + Copy>(items: &[T]) -> T {
    let mut max = items[0];
    for &i in items { if i > max { max = i; } }
    max
}

let shapes: Vec<Box<dyn Shape>> = vec![Box::new(Circle(1.0)), Box::new(Square(2.0))];
let total: f64 = shapes.iter().map(|s| s.area()).sum();
println!("{} {}", largest(&[3, 9, 2]), Square(2.0));   // 9 Квадрат 2
```
! Generics — статическая диспетчеризация, dyn — динамическая
! Реализуйте Display для вывода пользователю, Debug — для отладки
! impl Trait в аргументе — короткая запись generic

@lesson Время жизни, конкурентность и Cargo
Время жизни (lifetime) показывает компилятору, как долго действительна ссылка. Чаще всего оно выводится само; явно пишут, когда функция возвращает ссылку из одного из аргументов: `fn longest<'a>(a: &'a str, b: &'a str) -> &'a str`.
Конкурентность безопасна благодаря трейтам `Send` и `Sync`. Общие данные между потоками держат в `Arc<Mutex<T>>`: Arc — счётчик ссылок для потоков, Mutex — блокировка. Асинхронный код пишут через `async`/`.await` и рантайм `tokio`.
Cargo — менеджер пакетов и система сборки: `cargo new`, `cargo build --release`, `cargo test`, `cargo clippy`, `cargo fmt`. Зависимости (крейты) указывают в Cargo.toml.
```rust
use std::sync::{Arc, Mutex};
use std::thread;

fn longest<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() >= b.len() { a } else { b }
}

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let handles: Vec<_> = (0..4).map(|_| {
        let c = Arc::clone(&counter);
        thread::spawn(move || { *c.lock().unwrap() += 1; })
    }).collect();
    for h in handles { h.join().unwrap(); }
    println!("{} {}", *counter.lock().unwrap(), longest("rust", "go"));  // 4 rust
}

// Cargo.toml
// [dependencies]
// clap = { version = "4", features = ["derive"] }
// anyhow = "1"
```
! Rc — для одного потока, Arc — для многих
! move в замыкании переносит владение в поток
! cargo clippy подсказывает идиоматичный код
