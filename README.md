AVALAND

Learn programming through an interactive adventure

AVALAND is a gamified programming education platform where learners explore a world map, complete lessons, solve coding challenges, and develop practical coding skills. It combines structured learning paths with an interactive code editor and progress tracking.

Try AVALAND · GitHub repository

Overview

• 15 programming languages presented as explorable regions
• 120 lessons and 664 learning activities
• 88 coding challenges with test-based validation
• Code execution support for 14 languages
• Final exams, certificates, and periodic review
• User accounts and cloud-synced learning progress

Features

Interactive learning map

Explore programming languages through a game-inspired map and advance through lessons and challenges.

Built-in code editor

Write and execute code in an integrated editor. The project uses CodeMirror 6 and language-specific runtimes or compiler services, including Pyodide for Python.

Coding challenges and assessments

Practice with automated test cases, quizzes, final exams, and certificates to reinforce learning.

Progress synchronization

User authentication and cloud progress synchronization are powered by Supabase.

Web and mobile experience

AVALAND is accessible on the web, with a Capacitor-based iOS application project.
